# Welcome to my Neglected Github

### Exploring the possibilities of AI coding tools in healthcare applications

I am building proof of concept tools for various problems in healthcare. Mainly using this as a way to explore healthcare coding tools and teach myself. New projects coming soon. 

## 🔬 Projects

| Project | What it does | Built with |
|---|---|---|
| [**LifeSci Opportunity Scraper**](https://github.com/Jakeisaperson2/lifesci-opportunity-scraper) | Automatically discovers grants, RFPs, and clinical trials from 6 sources (NIH, ClinicalTrials.gov, Grants.gov, and more), matches them with a faculty research directory, and tracks leads in a built-in CRM | Python · FastAPI · SQLAlchemy · Tailwind |
| [**PartnershipOS**](https://github.com/Jakeisaperson2/partnership-os) | Turns Odoo's general-purpose CRM into a partnership-management platform for academic medical centers, with a 9-stage deal pipeline and automatic project creation | Odoo 17 · Python · PostgreSQL · Docker |
| [**Research Dashboard**](https://github.com/Jakeisaperson2/research-dashboard) · [live demo](https://jakeisaperson2.github.io/research-dashboard/) | Single-page dashboard combining researcher profiles, project status, and open industry RFPs | React · Tailwind CSS |
